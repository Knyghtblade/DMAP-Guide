DMAP GUIDE: REMOTE PC TEST

This shares the guide from this PC with a second PC (and phones) over a private Tailscale network.

BEFORE STARTING
1. Install Tailscale on both PCs from https://tailscale.com/download/windows.
2. Sign in to the same Tailscale account on both PCs. Wait until Tailscale says Connected.
3. If either PC belongs to your company, get permission before installing Tailscale.

ON THIS PC (the one hosting the guide)
1. Close DMAP Guide.
2. If a DMAP API window is open, click it and press Ctrl+C, then close it.
3. Open File Explorer and go to the DMAP Guide project folder.
4. Double-click Prepare Remote PC Test.cmd.
5. Wait for the window to say READY. Leave the new DMAP API window open.
6. The window shows the API address and the access key. Keep them for phones and for this PC.
7. The window also shows the path to a ZIP package. Copy that ZIP to the second PC using a USB drive or a company-approved file transfer.
8. To use the shared guide on this PC too, open DMAP Guide, choose Settings, pick The shared guide server, and enter the address and key.
   The first time, if the server is empty, DMAP Guide offers to copy this PC's guide to it.

ON THE SECOND PC
1. Make sure Tailscale says Connected.
2. Extract the ZIP. Open the extracted DMAP Guide folder.
3. Close DMAP Guide if it is already open.
4. Double-click Connect to DMAP Guide.cmd.
5. When the book window appears, click the cover to open it.
6. Make a small test edit and press Done. The host PC must stay on with the DMAP API window open.

This is a private proof-of-concept test. The package contains the guide's access key. Only transfer it to a
trusted PC on your private Tailscale network. Do not post or email it publicly.
